# SQL Projects & Capstones

Welcome to the hands-on project track for the SQL Curriculum. These projects are designed to transition you from writing isolated queries to designing and managing entire database systems.

## 🧠 Program Logic Flow

Projects follow a "Real-World Architecture" approach:
1.  **Schema Design**: Designing tables, relationships, and constraints.
2.  **Data Ingestion**: Populating the database with realistic data.
3.  **Business Intelligence**: Writing complex queries to extract actionable insights.
4.  **Optimization**: Ensuring the database stays fast as it grows.

## 🏆 Project Tracks

| Project | Level | Description |
| :--- | :--- | :--- |
| **[01: E-commerce Backend](./01-ecommerce-backend)** | Beginner | Design a database for a store (Products, Customers, Orders). |
| **[02: Social Network Analytics](./02-social-network)** | Intermediate | Complex JOINS and Subqueries for a social media platform. |
| **[03: Data Science Bridge](./03-data-science-bridge)** | Advanced | **SQL + Python Integration.** Querying data for analysis in Pandas. |

## 🚀 How to start
Choose a project that aligns with your interest. Each project contains a `spec.md` with requirements and a `solution/` folder for reference.
