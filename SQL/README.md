# SQL Curriculum

This curriculum follows the [roadmap.sh SQL Roadmap](https://roadmap.sh/sql) and adheres to the **Hook-Theory-Lab** pedagogical model.

## 🧠 Program Logic Flow

The course is structured to move from basic data retrieval to complex database engineering and performance optimization.

| Module | Topic | Description |
| :--- | :--- | :--- |
| **01** | [Introduction](./lessons/01-introduction) | Why databases? Relational vs. NoSQL. |
| **02** | [Basic Syntax](./lessons/02-basic-syntax) | Core keywords, data types, and CRUD basics. |
| **03** | [DDL (Data Definition)](./lessons/03-ddl) | Creating and managing tables (CREATE, ALTER, DROP). |
| **04** | [DML (Filtering & Sorting)](./lessons/04-dml-filtering-sorting) | Advanced querying with WHERE, ORDER BY, and LIMIT. |
| **05** | [Aggregates & Grouping](./lessons/05-aggregates-grouping) | Data analysis with GROUP BY and aggregate functions. |
| **06** | [Constraints & Keys](./lessons/06-constraints-keys) | Data integrity with PK, FK, and Unique constraints. |
| **07** | [Joins](./lessons/07-joins) | Combining data from multiple tables. |
| **08** | [Subqueries](./lessons/08-subqueries) | Nested and correlated queries. |
| **09** | [Built-in Functions](./lessons/09-functions) | String, Numeric, and Date manipulations. |
| **10** | [Views & Indexes](./lessons/10-views-indexes) | Virtual tables and performance basics. |
| **11** | [Transactions & Security](./lessons/11-transactions-security) | ACID properties, COMMIT/ROLLBACK, and permissions. |
| **12** | [Performance Optimization](./lessons/12-performance) | Query analysis and optimization techniques. |
| **13** | [Advanced Topics](./lessons/13-advanced-topics) | CTEs, Window Functions, and Stored Procedures. |
| **14** | [Triggers & Automation](./lessons/14-triggers-automation) | Automating actions with Triggers and Audit Logs. |

## 🏆 Project Tracks (Capstones)

Once you have completed the lessons, put your skills to the test with real-world projects:
- **[E-commerce Backend](./projects/01-ecommerce-backend)**: Schema design and business reporting.
- **[Social Network Analytics](./projects/02-social-network)**: Complex joins and user data analysis.
- **[Data Science Bridge](./projects/03-data-science-bridge)**: Connecting SQL with Python and Pandas for advanced analytics.

## 🛠️ Pedagogical Model: Hook-Theory-Lab

Each lesson directory contains:
1.  **`README.md`**: 
    - **Hook**: A real-world problem to create intellectual need.
    - **Theory**: Technical explanation and syntax.
    - **Hebrew Summary**: A concise summary in Hebrew.
2.  **`theory.sql`**: Executable code examples used during the theory phase.
3.  **`lab/`**:
    - **`exercises.md`**: Practical tasks for students.
    - **`solution.sql`**: Reference solutions.
