# Lab 02: Your First Queries

## Goal
Practice using the `SELECT` statement to retrieve data from a database.

## Preparation
Imagine a table named `students` with the following columns:
- `student_id`
- `first_name`
- `last_name`
- `email`
- `grade_point_average`

## Tasks

### 1. The Overview
Write a query to retrieve **all** information about **all** students.

### 2. Contact List
Write a query to retrieve only the `first_name`, `last_name`, and `email` of all students.

### 3. Graduation Check
Write a query to retrieve the `first_name` and the `grade_point_average` of all students.

### 4. Renaming Results
Write a query to retrieve the `first_name` and `last_name`, but display the `last_name` as `family_name` in the results.

---

## Instructions
Write your SQL queries in a text file. You can check the `solution.sql` file to verify your answers.
