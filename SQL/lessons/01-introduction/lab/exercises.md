# Lab 01: Environment Check

## Goal
Verify that your SQL environment (VS Code Extension, DBeaver, or Online Fiddle) is working correctly.

## Tasks

### 1. The Welcome Query
Run a query that returns the text `"Welcome to SQL Course"`.

### 2. Math Test
Calculate the result of `(25 * 4) + 50` using SQL.

### 3. Identify your Engine
Run a query to find out the current date and time from the database.

---

## Instructions
1. Open your SQL editor.
2. Copy each task's logic and run it.
3. Compare with `solution.sql`.
