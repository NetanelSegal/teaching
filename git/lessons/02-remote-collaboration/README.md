# Module 2: Remote Collaboration

This module bridges the gap between your local environment and cloud-based hosting platforms like GitHub, enabling team collaboration.

## Lessons
1.  **[Introduction to Remotes](./01-intro-to-remotes/)**: Connect your local work to the cloud with `clone` and `remote`.
2.  **[Pushing and Pulling](./02-pushing-and-pulling/)**: Synchronize your work with other team members.
3.  **[Collaboration Workflow](./03-collaboration-workflow/)**: Learn the professional industry standard: Forks and Pull Requests.
