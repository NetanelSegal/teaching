# Module 0: Git Foundations

This module covers the core concepts and commands required to use Git effectively on a single machine.

## Lessons
1.  **[Why Version Control?](./01-why-vcs/)**: Understand the evolution of VCS and why Git is the industry standard.
2.  **[Your First Repo](./02-your-first-repo/)**: Learn how to initialize a repository and track files.
3.  **[Staging and Committing](./03-staging-and-committing/)**: Master the three-stage architecture of Git.
4.  **[Viewing History](./04-viewing-history/)**: Learn how to use `log` and `diff` to see your project's past.
5.  **[Ignoring Files](./05-ignoring-files/)**: Protect your repo from noise and sensitive data with `.gitignore`.
6.  **[Undoing Changes](./06-undoing-changes/)**: Learn how to fix mistakes and recover deleted work.
