# Lab 4: Exploring the Timeline

## Goal
Practice using `log` and `diff` to understand changes in a repository.

## Tasks

### 1. Preparation
Continue working in your `lab-03-git` folder from the previous lesson, or create a new one with at least 2 commits.

### 2. Make a Modification
Modify `script.js` by adding a new line of code (e.g., `console.log("Learning Git History");`).

### 3. Inspect the Change
Before staging, run a command to see exactly what you changed compared to the last commit.

### 4. Stage and Review
Stage the change. Now, run a command to see what is currently in the staging area ready to be committed.

### 5. Final Commit
Commit the change with the message "Add history learning log".

### 6. History Review
Run two variations of the `log` command:
1. One that shows the full history.
2. One that shows each commit as a single line.

### 7. Patch View
Run a command that shows the history along with the actual code changes made in each commit.

---

## Instructions
Complete these tasks in your terminal. You can use the `solution.sh` script to see the expected commands.
