# Lab 2: Your First Repo

## Tasks

### 1. Create a Project Folder
Create a new directory on your machine named `git-practice`. Navigate into it.

### 2. Initialize Git
Turn this folder into a Git repository.

### 3. Verify the Initialization
- Check if the `.git` folder was created (remember to use the command that shows hidden files).
- Run the command to check the "status" of the repository.

### 4. Create your first file
Create a file named `hello.txt` with some text inside.

### 5. Inspect the "Untracked" State
Check the status again. Observe how Git describes the new file.

---

## Instructions
Complete these tasks in your terminal. You can reference `solution.sh` if you get stuck.
