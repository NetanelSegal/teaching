# Lab 1: Getting Ready for the Journey

## Tasks

### 1. Installation
Ensure Git is installed on your machine.
- If you don't have it, download it from [git-scm.com](https://git-scm.com/downloads).

### 2. Verify Installation
Open your terminal and check the version of Git.

### 3. Identity Configuration
Set your professional identity in Git. Every commit you make will be tagged with this name and email.

### 4. Default Branch
Set your default branch name to `main` to align with modern industry standards.

### 5. Review Settings
List all your global configurations to verify they are correct.

---

## Instructions
Complete these tasks in your terminal. When finished, you can check the `solution.sh` file for the exact commands.
