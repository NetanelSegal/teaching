# Lab 3: Staging and Committing

## Goal
Practice the `add` and `commit` workflow to create a history of your project.

## Tasks

### 1. New Project
Create a folder named `lab-03-git` and initialize it as a Git repository.

### 2. Create Content
Create two files:
- `script.js` with some content (e.g., `console.log("Hello Git");`).
- `README.md` with a title.

### 3. Selective Staging
Stage **only** `README.md` and check the status of your repository.

### 4. First Commit
Commit the staged `README.md` with the message "Add project documentation".

### 5. Remaining Work
Stage the `script.js` file and commit it with the message "Initialize JavaScript logic".

### 6. Verification
Run `git status` to ensure your working tree is clean.

---

## Instructions
Complete these tasks in your terminal. You can use the `solution.sh` script to see the expected commands.
