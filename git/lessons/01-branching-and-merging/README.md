# Module 1: Branching and Merging

This module introduces parallel development workflows, allowing you to work on multiple features without breaking your stable code.

## Lessons
1.  **[What is a Branch?](./01-what-is-a-branch/)**: Understand branches as lightweight pointers to commits.
2.  **[Switching and Merging](./02-switching-and-merging/)**: Master the feature-branch workflow.
3.  **[Handling Conflicts](./03-handling-conflicts/)**: Learn how to resolve collisions when code overlaps.
