# Lab 1: Planting a Branch

## Goal
Practice creating and managing branches to understand how Git handles parallel pointers.

## Tasks

### 1. Preparation
Create a new folder `lab-branching` and initialize it. Make at least one commit.

### 2. The First Branch
Create a new branch named `development`.

### 3. Verification
Run a command to list all branches in your repository. Which branch are you currently on?

### 4. The Experimental Branch
Create another branch named `crazy-experiment`.

### 5. Detailed View
Run `git log --oneline --decorate`. You should see that `main`, `development`, and `crazy-experiment` are all pointing to the exact same commit.

### 6. Cleanup
Delete the `crazy-experiment` branch. Verify that it's gone.

---

## Instructions
Complete these tasks in your terminal. You can use the `solution.sh` script to see the expected commands.
