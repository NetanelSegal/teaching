# TypeScript Professional Engineering Curriculum

This curriculum provides a deep dive into TypeScript, taking students from "JavaScript-like" code to professional-grade type-safe architecture. It is aligned with `roadmap.sh` and modern industry standards for high-scale frontend and backend development.

## 📂 Repository Structure

-   **[lessons/](./lessons/)**: Theoretical modules following the "Hook-Theory-Lab" model.
-   **[exercises/](./exercises/)**: Progressive practice labs from basic types to complex generic systems.

## 🚀 The Learning Path

1.  **Foundations (01-02):** Moving from dynamic to static typing. Setup and the "Why?".
2.  **The Type System (03-04):** Master Interfaces, Types, Unions, and the difference between `any` and `unknown`.
3.  **Generics & Advanced Patterns (05-07):** Building reusable, type-safe logic and complex transformations.
4.  **OOP & Ecosystem (08-09):** Engineering scalable architectures and integrating with React/Node.js.

## 🛠️ Standards & Conventions
-   **Safety First:** We enable `strict` mode by default and discourage the use of `any`.
-   **Pedagogy:** Every module follows the **Hook-Theory-Lab** sequence to ensure intellectual need is met before theory is introduced.
-   **Modern TS:** All examples use ESM, `template literals`, and modern utility types.
-   **Bilingual Support:** Technical concepts include Hebrew translations to aid comprehension.
