# Lesson 15: Async / Await Practice

This folder contains exercises designed to sharpen your skills with modern asynchronous JavaScript.

## Practice Goals
- **Refactoring**: Moving from `.then()` chains to cleaner `async/await` syntax.
- **Robust Error Handling**: Mastering `try/catch` and manual error throwing for network requests.
- **Performance**: Using `Promise.all()` to handle multiple requests in parallel.

## Exercises
1. **The Modern Fetcher**: Converting old Promise code to modern syntax.
2. **Safe User Search**: Handling network errors and missing data professionally.
3. **Parallel Profile Fetcher**: Optimizing performance with concurrency.

## How to use
Open `exercises.js` and write your solutions. You can test your code using the browser console or Node.js.
