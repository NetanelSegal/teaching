# AI Engineering Projects

This directory contains long-form projects and capstone assignments for the AI Engineering course.

## Project List

### [Final Project: The Autonomous AI Support System](./final_project/spec.md)
A comprehensive system that integrates RAG, Agents, Vision, and Production-ready features into a single customer support application.

## Guidelines
- Projects should be implemented in Node.js (ES Modules).
- Use `dotenv` for secret management.
- Ensure all AI responses are validated using `Zod`.
- Projects must include a `spec.md` and a functional `README.md` in their respective folders.
